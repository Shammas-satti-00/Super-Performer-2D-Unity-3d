# 🎮 Super Runner 2D Unity 3D

A **2D Mario-style platformer** built in **Unity**, featuring smooth character control, animations, checkpoints, and sound effects.  
Developed as part of the *Unity Video Games* series by **Shammas-satti-00**.

---

## 🧠 Game Overview

**Super Runner 2D Unity 3D** is a fast-paced, side-scrolling adventure where the player must navigate levels filled with enemies, coins, and obstacles.  
The game combines **2D gameplay mechanics** with **3D Unity tools** for a clean, modern look and performance.

### ✨ Features
- ⚙️ Smooth player movement and jumping
- 🎯 Checkpoint & respawn system
- 🌄 Multiple level environments
- 🔊 Sound effects and music
- 💾 Progress saving (PlayerPrefs-based)
- 🎮 Optimized for both **PC** and **Android** builds

---

## 🚀 How to Play

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Shammas-satti-00/Super-Runner-2D-Unity-3d.git
   ```
2. Open the project in **Unity (2021 or newer)**
3. Open the main scene (e.g., `Level1.unity`)
4. Press **Play** ▶️ in the Unity editor

---

## 🛠️ Build Instructions

### For PC
1. Go to **File → Build Settings**
2. Select **PC, Mac & Linux Standalone**
3. Click **Build and Run**

### For Android
1. Switch Platform → **Android**
2. Set up your keystore if needed
3. Build APK and install on your device
